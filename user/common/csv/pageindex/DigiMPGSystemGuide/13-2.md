入力カラムを維持しつつ、以下を追加（既存なら上書き）:

| 列 | 内容 |
|------|------|
| `Persona` | 実行したペルソナ名（マルチペルソナ時のみ）。0/1 ペルソナでは空 |
| `Answer` | エージェントの応答 |
| `Verdict` | LLM 判定 (○ / △ / ✕) |
| `Score` | 0-100 (LLM が `Ground Truth` と比較) |
| `Match` | `Y`/`N` — 文字列正規化後の完全一致 |
| `Seq Ratio` | `difflib.SequenceMatcher` 類似度 (0-1) |
| `Token F1` | 英数語＋CJK字単位のトークン重なり F1 (0-1) |
| `Eval` | LLM の 1 行コメント |
