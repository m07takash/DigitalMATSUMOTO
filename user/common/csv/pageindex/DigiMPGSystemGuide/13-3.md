- **行ごとの履歴制御は `Memory No` 列で完結**: 旧 `Memory Use (BatchTest only)` チェックボックスは廃止。チェックボックスより `No` + `Memory No` 列の組み合わせの方が「この質問は1行目と3行目だけ参照」「この質問は履歴なし」など粒度の高い制御ができる
- **`Save Digest (BatchTest only)` チェックボックス**: digest 生成を抑止する独立トグル。OFF で大量実行のコスト/時間を節約。チャットヘッダーの `Save Digest` とは独立
- **`Eval only` チェックボックス**: エージェント呼び出しをスキップし、既存の `Answer` + `Ground Truth` 列だけを `eval_answer_vs_groundtruth` で **再評価** するモード。Verdict / Score / Match / Seq Ratio / Token F1 / Eval 列を上書き。**`Question` 列は評価コンテキストとして参照される (なくても実行可)**。LLM 生成コストなしで再スコアリングしたい時に高速
- **`Baseline` / `BaselineModel` 列は上書きされない**: 入力にあれば出力にそのまま残る。Personal Evaluation 側で集約評価に使う
- **書式保持出力**: `Answer` 生成した結果 xlsx は、**元 Excel の書式 (列幅・塗り・フォント・フリーズペイン・非対象シート)** を openpyxl オーバーレイで維持。行数が変わる場合 (multi-persona 展開) のみ pandas ベースの新規書き込みに自動フォールバック
- **サイドバーのペルソナ選択を反映**: `selected_persona_ids` に2件以上ある時、各質問は **マルチペルソナ並列実行**で走り、結果は **Long Format（1質問 × N行）** で書き出される
- **進捗表示**: サイドバーの bg-task メッセージに `(N/N) Running batch Q&A...` 形式でリアルタイム表示（ペルソナ完了単位でカウント）。Eval only 時は `(N/N) Re-evaluating Answer vs GT...`
- **結果ファイル選択**: 過去の `batch_results_*.xlsx` / `batch_results_evalonly_*.xlsx` をドロップダウンで切替えてダウンロード／分析可
