`Plugin` に以下を追加すると WebUI が対応した振る舞いをします:

| フック | 目的 |
|---|---|
| `default_agent() -> str` | 「Run analysis の LLM 構造化分析」で使う **専用エージェント** ファイル名。指定するとエージェント選択の代わりに固定表示 (再現性重視) |
| `list_categories() -> list[str]` | Run analysis 前に表示するカテゴリー選択チェックボックス群のラベル。指定カテゴリのみ集計 / render / report / save |
| `llm_augment(result, agent_file, service_info, user_info, categories=None) -> dict` | Run analysis 時に自動発火。カテゴリごとの LLM 構造化分析 (例: 人格形成のルーブリック、目標の構造抽出) を **並列** 実行し、`{session_state_key: cache_entry}` を返す。エラーは `_llm_augment_errors` 特殊キーで surface |
