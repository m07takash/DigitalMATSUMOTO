人格評価7理論 (Big Five / Schwartz Value Theory / Self-Determination / Personal Strivings / Narrative Identity / Social Identity / Attachment) を一括スコアリング。テンプレートはプラグインフォルダ直下に同梱 (`user/common/evaluation/PersonalEvaluation/PersonalTestQA.xlsx`) — UI の `Download template (.xlsx)` ボタンから取得。

**入力 Excel**: 2シート構成
- `Category` シート: 7 行 (理論メタ情報)
- `PersonalTest` シート: Q/A 行 (`No / Category / Question Style / Question / Memory No / Memo / Answer / Ground Truth / Baseline / BaselineModel / Compare`)

**Baseline 列**: `Answer(AI)` (被評価エージェント) と `Ground Truth` (対象者) とは別に、汎用モデル (`BaselineModel`) の回答を入れておくと、以下が追加表示されます:

- サマリータイル: 「Answer(AI)↔Baseline の Cos/MAE」 「GroundTruth↔Baseline の Cos/MAE」を半サイズで併記
- サマリーレーダー: 左右 2 分割 (Cos / MAE) × 3 系列 (A↔GT=青, A↔B=橙, GT↔B=茶)
- 各カテゴリ (特性 / 価値観 / 動機 / 社会性 / 愛着): Baseline 列 + Diff(A-B) + Diff(GT-B) をスコア表に追加、レーダーにも Baseline の 3 本目トレース (オレンジ)
- **人格形成 / 目標は Baseline スコアリング対象外** (エピソード比較のため)

**スコアリング (Likert 系)**:
- `Memo` 列から `(軸名, reverse フラグ)` を自動解析 (例: 「神経症傾向の逆（Emotional Stability）」 → axis=`Emotional Stability`, reverse=True)
- Answer のキーワード → 0–1 スコア: `はい/Agree`→1.0, `どちらでもない/Neutral`→0.5, `いいえ/Disagree`→0.0、または `1-5` / `1-7` の数値スケール
- Answer(AI) と Ground Truth の両方を並行スコアリングし、Cos 類似度 + MAE + Diff で提示

**目標カテゴリの重み付き F1/P/R スコアリング**:

- **重み** = 各目標の 4 軸 (大切さ/本気度/達成見込/達成度) を H=1.0 / M=0.5 / L=0.0 で平均
- **Precision** = Σ(共通目標の GT 重み) / Σ(全 GT 目標重み)  ← GT 基準
- **Recall** = Σ(共通目標の Answer 重み) / Σ(全 Answer 目標重み)  ← Answer 基準
- **F1** = 2·P·R / (P + R)
- **関係 F1 / P / R** = (from, to, kind) タプル集合の Precision / Recall / F1 (参考値、シナジー/トレードオフ内訳付き)
- **G3 決定論的パーサ** — LLM が `edges_answer` / `edges_gt` を空で返した場合でも、G3 テキストから `X と Y: シナジー` / `X と Y: トレードオフ` パターンを regex 抽出してマージ (LLM の抜けを補完)
- **N:N 対応** — Answer#a を GT-common#i に手動でペア (`_shared_gt_with_common`)。GT 重みは重複計上しない (dedup)

**目標マトリクスの手動編集** (LLM の判定を後から修正できる):

- **✏️ 共通する目標の分類を編集** (折り畳み可): 各 LLM 共通目標に「☐ 共通していない」チェックボックス (split)、既存の手動ペアに「☐ 共通していない」チェックボックス (unpair)
- **✏️ 共通しない目標の分類を編集** (折り畳み可): 各 Answer-only 目標に「🔽 分類」selectbox (`共通していない (このまま)` / `GT-only#j` / `GT-共通#i` から選択) — GT-共通に紐付けると N:N クロスペア成立、既存 split エントリに「共通に戻す」ボタン
- **✓ 変更を適用** ボタンで全 pending 変更を一括反映 (widget の都度 rerun なし)。**F1/P/R / サマリータイル / メトリック帯すべてが再計算**
- **🔄 分類をリセット** で全手動変更をクリア
- 表示は Answer/GT どちらも **同一文の重複を dedup** (LLM が同じ文を複数の対と結ぶ N:M ケースも一覧はスッキリ)
